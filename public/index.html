OpenSky Private API

Returns live aircraft state vectors as JSON.

Usage

/api?key=aritra /api=aritra?key=aritra /api?key=aritra&lamin=45.8&lomin=5.6&lamax=47.8&lomax=10.5

Optional parameters

lamin, lomin, lamax, lomax — bounding box icao24 — single aircraft hex address time — unix timestamp limit — max aircraft returned (default 500, max 5000)
